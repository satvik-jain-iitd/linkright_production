## [type: Added]

- **UAT Cluster E2 — Layout primitives:** Added `linkright/ui/layout.py` with seven new TUI primitives layered on the E1 tokens + iconography foundation: `horizontal_divider()` / `turn_divider()` to wrap role-based interactions with structural rules (#14), `sticky_footer(tier, mode, status)` rendering a single-line three-segment badge bar with semantic colors — gold/orange tier, mint/teal mode, muted status — and automatic vertical stacking on narrow terminals (#16), `tab_bar()` for display + `tab_navigate()` interactive prompt_toolkit navigator binding Tab / Shift-Tab / Left / Right / h / l keys with a numbered-picker non-TTY fallback so headless contexts never silently no-op (#17), and `l_branch_tip()` / `l_branch_group()` rendering muted-gray `└` / `├` branch lines for secondary information and tip clusters (#22). Wired the divider + tip + sticky-footer into three surfaces per spec §2/§3 of `specs/cluster-e-ui-design-system.md`: (a) `linkright doctor` success + failure paths and the no-subcommand `linkright` cheat-sheet; (b) `linkright profile show` — `horizontal_divider` between the populated tree and the "not yet populated" advisory block plus `sticky_footer(mode='profile', status=N nuggets)` at the surface bottom; (c) `linkright resume tailor` — `horizontal_divider` before the success card plus `sticky_footer(mode='tailor', status=duration)` after, both placed outside the orchestrator's `rich.live` progress region so they never overlap streaming updates. Migrated the existing "Tip: edit ~/.linkright/config.yaml" line in `setup_wizard.py` and the "Tip: add these sections..." line in `profile/render.py` to the new `l_branch_tip()` primitive. Wired `tab_navigate()` into the canonical multi-step picker entry point `linkright.prompts.prompt_for_choice` via an opt-in `LR_PICKER_STYLE=tabs` env var — when the option set is small (≤4 options, ≤30-char labels), the prompt swaps questionary's vertical select for the new horizontal Tab/Shift-Tab navigator. This covers every multi-step picker call site in v1 (setup wizard's 3 sequential picks across embedder + PDF + LLM-mode, `prompt_for_resume_source`, `prompt_for_jd_input`) without changing default UX for users who don't set the env var. All primitives are additive — no E1 work was refactored. Test suite expanded to 32 cases at `tests/test_uat_cluster_e2.py`: the original 26 (rule character + width + indent, sticky-footer semantic colors via ANSI assertion + narrow-terminal stacking, tab_bar markers, tab_navigate non-TTY fallback paths, L-branch alignment under multi-byte content) plus 6 new wiring tests — 3 for `prompt_for_choice` ↔ `tab_navigate` routing (env-var on → tab path, env-var off → questionary path, long-label fallback), 1 boundary-check on the eligibility predicate, 1 for `_render_success_card` emitting the divider + sticky_footer at the tailor exit boundary, and 1 for `show_profile` emitting the sticky_footer. Resolves UAT bugs #14, #16, #17, #22.
